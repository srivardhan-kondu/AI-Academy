# Machine Learning Engineer: Course Notes

In-depth study notes for every topic in the Machine Learning Engineer curriculum.
Each topic follows the same pattern, adapted from the house teaching method
(`docs/04-lesson-template-and-teaching-method.md`):

- **In plain English**: the idea without jargon
- **How it works**: the mechanism, the maths and, where useful, runnable Python
- **Pitfalls**: the mistakes learners and practitioners actually make
- **Check yourself**: one question that tests understanding, not memory

All code targets Python 3.11+, NumPy 2.x, pandas 2.x, scikit-learn 1.5+ and PyTorch 2.x.
