# AI Learning Platform Blueprint

A complete product, curriculum, learning-experience and technical blueprint for building an interactive AI education platform.

## Product principle

**Learn difficult things the easy way.**

The platform should help beginners understand AI without sacrificing the technical depth required by students, developers and professionals.

The core learning loop is:

**Understand → Visualize → Experiment → Implement → Practice → Apply**

## Recommended implementation order

1. Read the product vision and scope.
2. Approve the curriculum and learning paths.
3. Design the lesson experience.
4. Build the content model and admin CMS.
5. Implement the lesson renderer and interactive lab framework.
6. Launch with a small number of excellent lessons.
7. Expand the curriculum based on learner feedback.

## Initial launch targets

These are planning targets, not existing content counts:

- 19 curriculum schools defined
- 5 structured learning paths
- 30 high-quality lessons
- 10 interactive visualizations
- 5 practical projects
- Student accounts and progress tracking
- Admin CMS
- Free and premium content permissions

## Important product rule

Do not optimize for the number of lessons. Optimize for whether learners can explain a concept, use it correctly and apply it to a practical problem.
