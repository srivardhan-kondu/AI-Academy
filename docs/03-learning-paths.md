# Learning Paths

Learning paths connect schools into goal-oriented journeys. Students should be able to follow a path or explore lessons independently.

## Path 1 — AI for Absolute Beginners

**Audience:** Students and non-technical learners.

Sequence:
1. AI Fundamentals
2. AI vs ML vs Deep Learning
3. How AI systems learn
4. Generative AI fundamentals
5. Prompt Engineering basics
6. AI tools for everyday tasks
7. Responsible AI use
8. Beginner practical project

**Capstone:** Create a useful AI-assisted study or productivity workflow.

## Path 2 — Python for AI

**Audience:** Learners who want a programming foundation.

Sequence:
1. Python setup
2. Variables and data types
3. Conditions and loops
4. Functions
5. Data structures
6. Files and exceptions
7. NumPy
8. Pandas
9. Matplotlib
10. Working with APIs
11. Data-focused mini project

**Capstone:** Analyze a dataset and build a small Python application.

## Learning path data requirements

Every path should store:
- Name and description
- Intended audience
- Difficulty
- Prerequisites
- Ordered modules
- Estimated effort
- Learning outcomes
- Free or premium access
- Capstone project
- Publication status

## Personalization

Initially, recommend paths using a short goal-selection flow. Do not build a complex AI recommendation engine before collecting meaningful learning data.
