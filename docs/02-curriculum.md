# Complete AI Learning Curriculum

## Curriculum structure

Organize the curriculum into four broad levels. Learners can follow a recommended path or explore individual schools independently.

- **Level 1 — Foundations**
- **Level 2 — Core AI Engineering**
- **Level 3 — Modern AI Engineering**
- **Level 4 — Production and Specialization**

A school contains modules. A module contains ordered lessons. Lessons may include explanations, visualizations, experiments, code, quizzes and projects.

## Curriculum governance

- Assign each topic a level, school and prerequisite.
- Mark lessons as beginner, intermediate or advanced.
- Separate conceptual understanding from implementation depth.
- Include references for technical claims.
- Add a last-reviewed date to fast-changing topics.
- Avoid duplicate lessons across schools; link to shared foundational lessons where possible.
- Review learning paths periodically as tools and industry practices change.
