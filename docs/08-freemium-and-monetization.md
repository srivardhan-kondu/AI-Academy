# Freemium Model and Monetization

## 1. Business model

Use a freemium model: meaningful free education with paid depth, advanced practice and structured premium experiences.

The free tier should help a learner make real progress. It should not be a teaser that blocks basic understanding.

## 2. Free plan

Potential inclusions:
- Selected foundational learning paths
- Foundational lessons
- Selected interactive visualizations
- Basic quizzes
- Public articles and explainers
- Selected AI tools directory entries
- Selected project guides
- Basic student dashboard
- Bookmarks and lesson progress

## 3. Premium plan

Potential inclusions:
- Complete advanced learning paths
- Premium interactive labs
- Extended coding playground usage
- Advanced projects
- Premium downloadable resources
- Advanced assessments
- Structured career preparation
- Additional project feedback or workshops where offered

## 4. Access design principles

- Keep introductory explanations available for free.
- Make the free-to-premium distinction clear before a learner starts a locked activity.
- Do not erase progress when a subscription expires.
- Let users access their own learning history.
- Verify entitlements server-side.
- Avoid misleading countdowns and manipulative upgrade prompts.
- Clearly state renewal, cancellation and refund terms.

## 5. Possible additional revenue streams

- Paid workshops
- University and institutional training
- Corporate AI training
- Premium project cohorts
- Sponsored educational content with clear disclosure
- Carefully selected affiliate links for tools

Do not let sponsorship influence educational conclusions or tool reviews.

## 6. Pricing strategy

Do not set prices based only on competitor pricing. Validate:
- Student willingness to pay
- Payment preferences in target markets
- Content production cost
- Code execution cost
- Support cost
- Payment processing and tax obligations
- Premium conversion and retention

Run a small pilot before committing to annual pricing.

## 7. Metrics

- Free-to-paid conversion
- Paid retention
- Subscription cancellation
- Lesson completion by plan
- Premium feature usage
- Revenue per active learner
- Refund and support rates
- Cost per active learner
